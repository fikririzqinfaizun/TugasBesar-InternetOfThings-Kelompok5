## 📄 Ringkasan Proyek
Smart Fashion Inventory adalah sistem manajemen pergudangan dan inventaris pakaian berbasis IoT yang mengintegrasikan ESP32, kontrol kecepatan PID, indikator rak LED, dan Web Dashboard Laravel[cite: 12, 13, 14, 19].

## 🛠️ Arsitektur Sistem
- **Hardware:** ESP32 DevKit V1, Sensor IR, Motor DC TT, Driver L298N, Encoder HC-020K, LED Rak A/B/C[cite: 14, 16].
- **Backend:** Laravel 10 (SQLite)[cite: 12, 21, 22].
- **Fitur Utama:** Real-time Monitoring, PID Motor Control (50 RPM), Auto Rack Selection, dan QR Code Traceability[cite: 16, 17, 18, 21].
