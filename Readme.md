## Deskripsi Proyek

Smart Fashion Inventory merupakan proyek berbasis Internet of Things (IoT) yang dirancang untuk membantu UMKM fashion dalam memantau proses produksi dan mengelola persediaan pakaian secara otomatis.

Proyek ini berfokus pada penerapan sistem kendali PID untuk mengatur kecepatan konveyor mini menggunakan ESP32. Sistem kendali tersebut menggunakan encoder sebagai umpan balik untuk menjaga kecepatan konveyor agar tetap sesuai dengan nilai setpoint, meskipun terjadi perubahan beban atau tegangan suplai.

Selain sistem kendali konveyor, proyek ini dilengkapi dengan sensor inframerah (IR) untuk menghitung jumlah pakaian, indikator LED untuk menunjukkan rak tujuan, serta dashboard berbasis web untuk memantau jumlah produksi, stok tersedia, dan barang terjual secara real-time.

## Tujuan Proyek

1. Menjaga kecepatan konveyor agar tetap stabil pada nilai setpoint menggunakan kontroler PID.
2. Menghitung jumlah pakaian yang melewati konveyor secara otomatis menggunakan sensor IR.
3. Menentukan rak penyimpanan pakaian menggunakan indikator LED.
4. Memantau jumlah produksi, stok tersedia, dan barang terjual melalui dashboard.
5. Membantu meningkatkan konsistensi proses penyimpanan dan pengelolaan persediaan pakaian.
